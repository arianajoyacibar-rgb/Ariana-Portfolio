# FocusFlow

A study planner with a Pomodoro timer. Add tasks by subject, pick one to focus on, and track sessions and focus minutes.

## Features
- 25 / 5 / 15 minute timer with a progress dial and tab-title countdown
- Tasks with subjects, completion checkboxes and a per-task pomodoro count
- Stats: tasks done, sessions, focus minutes
- Dark mode, keyboard-accessible controls, data saved in `localStorage`

## Run
Open `index.html`. No build step.
