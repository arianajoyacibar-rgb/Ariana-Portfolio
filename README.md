# Ariana Joy Acibar — Portfolio

Portfolio of Ariana Joy Acibar, a 4th-year BSIT student at Nueva Ecija University of Science and Technology (NEUST), looking for a junior developer role during her internship.

**Live site:** https://arianajoyacibar-rgb.github.io/Ariana-Portfolio/

## What's inside
A single-page site built with HTML, CSS and JavaScript. No build step, no frameworks.

- Project filters, live-demo viewer (desktop and phone preview) and case studies
- Settings panel: color theme, animation level (full, subtle, off), text size and cursor glow
- Certifications with links to the certificates
- Responsive layout, keyboard-friendly, respects reduced-motion preferences
